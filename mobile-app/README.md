# Crooked Guess: Android app

This folder turns the game (`../index.html`) into an Android app with [Capacitor](https://capacitorjs.com),
adds AdMob rewarded videos for extra hints and a native LAN host for Versus, and has everything the
Play Store asks for.

```
mobile-app/
├── package.json, capacitor.config.json   app id com.soham.crookedguess, Capacitor 8
├── scripts/copy-web.js                   copies ../index.html into www/ (with the font bundled for offline play)
├── www/                                  generated by `npm run sync`, don't edit by hand
├── web-extra/fonts/                      Outfit font (SIL OFL) used by the app
├── android/                              the Android Studio project
│   └── app/src/main/java/com/soham/crookedguess/
│       ├── MainActivity.java             registers the LAN plugin
│       ├── LanServerPlugin.java          host a Versus game + find games nearby (UDP)
│       └── lan/LanRelay.java             tiny WebSocket relay the two phones play through
├── resources/                            icon source art (SVG)
└── store-listing/                        icon, feature graphic, 8 screenshots, texts, privacy policy
```

The game code lives in one place: **`gameM/index.html`**. Edit that, then run `npm run sync` to update the app.

---

## 1. One-time setup on your PC

1. Install **Node.js 22 or newer** (nodejs.org, LTS).
2. Install the latest **Android Studio** (2025.1.3 "Narwhal" or newer). In its first-run wizard, install the
   Android SDK. Then in *Settings > Languages & Frameworks > Android SDK* make sure **Android 16 (API 36)** is ticked.
3. Open a terminal (PowerShell) in this folder and install the packages:

   ```powershell
   cd "C:\Users\soham\OneDrive\Desktop\gameM\mobile-app"
   npm install
   npm run sync
   ```

> **OneDrive tip:** Gradle writes thousands of small files. If a build fails with "file is locked / access denied",
> pause OneDrive syncing while you build, or move the `gameM` folder outside OneDrive (for example `C:\dev\gameM`).

## 2. Run it on your phone

1. On the phone: *Settings > About phone*, tap **Build number** 7 times, then turn on
   *Developer options > USB debugging*. Plug it in and allow the prompt.
2. `npm run open` (opens Android Studio). Wait for "Gradle sync" to finish.
3. Pick your phone at the top and press ▶ **Run**.

After every change to `index.html`: `npm run sync`, then ▶ Run again.

## 3. Test the features

- **Extra hints / ads:** the app ships with Google's **test** ad IDs, so you see "Test Ad" videos. That's safe to tap.
  Use all hints in a game, tap **▶ Hint**, watch the video, and you get +1 hint (max 3 per game).
- **Versus:** install the app on two phones on the same Wi-Fi (or turn on one phone's hotspot and connect the other).
  Phone A: *Versus > Create game*. Phone B: *Versus* shows the game under **Join a game** within a second or two;
  if it doesn't (some routers block this), tap *Game not showing up?* and type the address shown on phone A.
  Some public/office Wi-Fi networks block devices from talking to each other ("client isolation"): use a hotspot then.
  If the app's Versus page ever talks about `node lan-server.js` or can't create a game, the app was built without
  Capacitor's runtime: run `npm install` then `npm run sync` (it copies `capacitor.js` into `www/`) and rebuild.
- **Web Versus:** on a computer on the same Wi-Fi run `node lan-server.js` in the `gameM` folder and open the
  address it prints on both devices. You can also join a phone-hosted game from that page by typing the phone's IP.

## 4. Set up AdMob (real ads = real money)

1. Create an account at **admob.google.com** (use the same Google account as your Play developer account).
2. *Apps > Add app > Android*. Choose "not published yet" for now; link it to the Play listing after release.
3. Copy the **App ID** (`ca-app-pub-XXXXXXXXXXXXXXXX~YYYYYYYYYY`) into
   `android/app/src/main/res/values/strings.xml` → `admob_app_id`.
4. *Ad units > Add ad unit > **Rewarded***. Name it "Extra hint", reward amount `1`, reward item `hint`.
   Copy the **ad unit ID** (`ca-app-pub-XXXXXXXXXXXXXXXX/ZZZZZZZZZZ`).
5. In `gameM/index.html` find `AD_CONFIG` near the top of the script and set:
   ```js
   androidRewardedId: 'ca-app-pub-XXXXXXXXXXXXXXXX/ZZZZZZZZZZ',   // your rewarded unit
   testing: false,
   ```
6. *Privacy & messaging > GDPR*: create a consent message (Google's form that the app already shows to EU/UK players).
7. `npm run sync`. From now on **never tap your own live ads** (AdMob bans accounts for that). To keep testing on your
   own phone, add it as a test device in *AdMob > Settings > Test devices*.
8. After your Play listing is live, put `store-listing/app-ads.txt` (with your publisher ID) at the root of your website.

## 5. Make the release build (AAB)

1. Create your **upload key** once and keep it safe (back it up; you need it for every update):
   ```powershell
   cd android
   & "C:\Program Files\Android\Android Studio\jbr\bin\keytool.exe" -genkeypair -v -keystore upload-key.jks -alias upload -keyalg RSA -keysize 2048 -validity 10000
   ```
2. Create `android/keystore.properties` (it's in `.gitignore`, never commit it):
   ```properties
   storeFile=upload-key.jks
   storePassword=YOUR_STORE_PASSWORD
   keyAlias=upload
   keyPassword=YOUR_KEY_PASSWORD
   ```
3. Build: `.\gradlew.bat bundleRelease` (inside `android`), or in Android Studio *Build > Generate Signed App Bundle*.
   The file is `android/app/build/outputs/bundle/release/app-release.aab`.
4. For every new upload, raise `versionCode` (1, 2, 3 …) and `versionName` in `android/app/build.gradle`.

The project targets **Android 16 (API 36)**, which is what Google Play requires for new apps and updates from 31 August 2026.

## 6. Publish on Google Play

1. Create a developer account at **play.google.com/console** (one-time US$25 fee, identity check).
2. *Create app*: name **Crooked Guess**, default language English, **Game**, **Free**.
3. *Store listing*: paste the texts from `store-listing/listing.md` and upload `icon-512.png`,
   `feature-graphic-1024x500.png` and the 8 files in `store-listing/screenshots/`.
4. *App content*: answer using `store-listing/play-console-answers.md` (privacy policy, ads, data safety,
   content rating, target audience, advertising ID).
5. *Testing > Closed testing*: upload the AAB. **New personal developer accounts must run a closed test with at
   least 12 testers who stay opted in for 14 days in a row** before Play unlocks production. Invite friends by email
   list or Google Group and ask them to keep the app installed.
6. After the 14 days: *Production > Create release*, upload the AAB (or promote the tested one), submit for review.
   First reviews usually take a few days.

## 7. Host the privacy policy (free)

Play needs a public URL. The quickest free option with your GitHub account:
1. Create a public repo, e.g. `crooked-guess`.
2. Upload `store-listing/privacy-policy.html` (and `app-ads.txt` if this will be your website).
3. Repo *Settings > Pages*: deploy from the `main` branch.
4. Your URL becomes `https://<your-username>.github.io/crooked-guess/privacy-policy.html`.
   (For `app-ads.txt` AdMob needs it at the domain root: use a repo named `<your-username>.github.io` for that file.)

### How Versus works (for the curious)

The host phone runs `LanRelay`, a tiny WebSocket server on port 8765, and sends a small UDP "game here" broadcast on
port 8766 every second. The other phone listens for those broadcasts to list the game. Both phones connect to the
relay, which numbers every message and echoes it to both of them in the same order, so both screens always agree on
who cracked the code first. `lan-server.js` in the `gameM` folder is the same relay for the browser version.
No internet and no server of yours is involved.
